# taamaraAPP: Event Management ERP

Internal operations system for the company: bookings with multiple functions, vendors, crew, tasks, schedules, money and communication in one place. Founder and co-founder are equal owners. Event managers, the accountant, supervisors, vendors and crew each get their own login and see only what their role allows.

**Status:** planning. No application code yet.

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md): requirements, architecture, permission matrix, database design and roadmap (v1.1, awaiting approval)
- [`docs/PROGRESS.md`](docs/PROGRESS.md): phase status and decisions log
- `docs/architecture.html`: the same plan as a styled page
- `archive/`: an early prototype, kept for reference only

Planned stack: Next.js, TypeScript, Tailwind CSS + shadcn/ui, PostgreSQL, Prisma, Better Auth, hosted on one server in AWS Mumbai (data stays in India).
