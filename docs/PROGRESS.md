| D62 | 26 Nov 2026 | How cash advances work (D57). A host gives an advance to a manager or supervisor (approved at once, and "handed over now" if the cash goes straight away); the accountant can prepare one, which waits in the approvals inbox, and a host who prepared one can't approve it while the other host is active. ## How to run it locally

```bash
cp .env.example .env          # then put random secrets in BETTER_AUTH_SECRET and FIELD_ENCRYPTION_KEY

npm run db:seed               # reference data + demo data (demo password: Taamara@2026)
npm run dev                   # http://localhost:3000
npm test                      # automated tests (needs TEST_DATABASE_URL)
```
